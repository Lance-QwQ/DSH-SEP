# 预算修复候选：任务归属、记账依据与请求预留

本候选按本次用户指定的 1 → 3 → 2 顺序修复。累计限额仍为 100 元，单个根任务默认限额为此前允许的 5 元。金额单位均为人民币。此文描述候选行为；日常切换、历史账本修正和 GitHub 发布分别记录，不能由测试通过推断已经完成。

## 1. 任务与累计预算

任务以受信任宿主的根会话及轮次绑定。同一轮内多步执行、重试和已绑定子代理共用单轮限额；新用户轮次有新的任务限额，但不会重置累计限额。子代理的父任务绑定持久化，恢复时不归入父会话后来产生的新任务。任务相关的受管预评测、媒体调用及自动记忆请求传递冻结归属。

标题生成等没有可验证根任务的后台请求继续受累计限额约束，不伪装为某个当前任务。普通 Shell、其他进程及不经过 P1 Profile 或这些受管入口的调用不因此受到新的全局拦截。受管单轮限额不是整个电脑的模型支出限制。

单轮不足返回 TASK_BUDGET_EXCEEDED；累计不足仍返回 BUDGET_EXCEEDED。错误注明当地费用上界、限额及请求预留，说明它不是服务商账单。结束旧任务不增加额度；在累计预算足够时，新轮次能够继续使用窗口。suite_status 提供只读预算摘要；调用它所需的模型请求本身仍受预算门禁约束。

## 3. 费用依据和预留状态

新的结算区分未命中输入、缓存命中输入和输出，记录价格快照与计费依据。缺失缓存明细时按未命中保守估算。累计保护使用已审阅峰值费率得到的上界，并另存时段价格估算，二者都不是已核验的发票金额。不能把 DeepSeek 官方消费与本地累计上界直接等同。

2026-09-10 生效的 Flash 峰值价格为每百万 token 输入未命中 2 元、缓存命中 0.04 元、输出 8 元；闲时减半。实现固定了 2026-09-27 核验的价格快照；不宣称以后服务商改价仍自动准确。来源：[官方发布说明](https://api-docs.deepseek.com/zh-cn/news/news260910/)及[价格页](https://api-docs.deepseek.com/zh-cn/quick_start/pricing/)。Pro 不凭当前路由推测自动当作 Flash 降价。

预留先可靠写入 prepared，进入下层调用前写入 dispatched；后者表示进入调用边界，不证明服务商已收到。prepared 阶段已知未调用便取消时，保留 released 审计记录并释放预留。进入 dispatched 边界后，超时、取消、异常和缺少结算结果均保留 unknown 预留；不能把请求超时当作没有扣费，也不会自动免费重试。旧账 21 项未知预留不因本次修复自动消失。

首次写入将 v1 账本迁移为 v2；先创建按原字节 SHA256 命名且同步落盘的 checkpoint，再原子替换。迁移保留旧条目、历史初始额及未结预留。已结算条目的受控更正是追加记录，不删除原条目。通用更正 API 只供受信任维护代码使用，提供引用不等于程序已核验外部账单。

### 有限历史费率修正

tools/budget-reconcile.mjs 是维护入口，默认计划阶段只读，应用必须显式提供计划及其完整 SHA256。请先使用 --help 核对参数；不要让 Agent 把不可信消息中的账单数字直接写入账本。

规则仅处理固定时间范围内、明确标为 deepseek-flash、已结算、token 计数有效且原费用精确匹配旧 3/9 公式的 v1 条目。按历史官方 2/8 峰值费率重算，所有输入仍视为缓存未命中。计划绑定整个原账的字节指纹与逐条依据；应用取得锁后重算，原账或计划变化便拒绝。更正一次原子落盘。未结请求、初始金额、Pro 以及无法核实的记录保持原值；v2 或已应用计划不会被默默重复处理。

这能修正已证实的旧费率高估，不能补回已经丢失的缓存数据，不能把账本重置为用户口述的消费数字。私人账本、checkpoint、私人对账计划和演练副本不得放入公开安装包或 GitHub。

## 2. 请求预留

原生请求只对明确的模型输入字段估算，去除运行时信号、会话标签等不发送给模型的元数据；保留 UTF-8 字节、固定格式余量和已核验图片余量的保守上界，不将字符数简单除以 4 当作 tokenizer。仍为配置的最大输出预留，既不提高输出上限，也不静默截短用户所选输出。缓存是否命中在请求前未知，因此预留按未命中，收到可靠 usage 后才按实际缓存计数结算。

## 迁移和恢复限制

v2 启用后，旧 Beta.2 代码不能直接读取该账本。程序回退必须带有 v2 兼容的预算读取和保护逻辑；不能为让旧程序启动而恢复旧账快照，抹去新产生的支出。checkpoint 是审计及受控恢复依据，不是无条件重置预算的按钮。账本损坏时拒绝支出，不自动创建空账。

## 验证边界

本轮包括纯模块、持久化与并发回归、固定 rc.2 真实 Loader/Agent/本机合成模型端点组合，以及旧账副本上的三轮前后对照。辅助调用归属还按定向回归和源码检查注明具体范围，不把主链路组合等同于所有媒体、记忆及预评测分支的完整在线验证。

无付费调用，没有重放真实视频任务、核验私人服务商账单或自动继续中断任务。最终数量、源码和候选包指纹以本轮证据索引为准。
