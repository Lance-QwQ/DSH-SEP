## 安装与数据位置

安装器只处理当前系统账户的 `~/Applications/DSH SEP.app`。账户主目录由系统账户记录确定，不接受通过 `HOME` 或命令行另指定安装目标。数据使用独立的 `~/Library/Application Support/DSH SEP/alpha2-mac-finder-preview`，安装事务记录位于 `~/Library/Application Support/DSH SEP Installer`。这些目录不应与官方 DSH 共享。

目前验证的是首次安装与受控恢复流程，不是覆盖任意已有程序的通用升级器。目标已有程序、来源不符或事务状态无法核验时，安装会拒绝；不要通过删除锁或修改事务文件强行继续。

窗口会先列出安装目标、数据位置、文件数量和计划哈希。点击 Install 后还需要确认该具体计划；取消审阅不会安装程序。成功提交后，Open DSH SEP 是单独操作。启动派发成功与应用健康检查通过是两个不同状态。

## 工作区与受控修改

本版采用受控工作副本。当前项目入口针对已绑定的单个项目；任意目录选择与自动纳管不在本轮范围内。项目页面展示当前项目、来源与副本状态，修改经过审阅和确认后提交为新的受管代次。原始导入目录保持不变，向外部来源导出尚未纳入本轮认证。项目管理授权与模型文件工具权限分开；模型不能以普通工具调用替代用户确认。关闭后恢复同一项目时，仍需原来的 P2 数据域权威与删除依据。项目页面整条操作链的验收状态仍以对应原生回执为准，不能从应用启动通过推断。

当前完整应用的固定 Profile 未开放普通 Shell、任务子进程或任意 MCP 接入；独立沙箱组件的测试不代表这些入口已在应用中启用。此预览不承诺任意第三方进程族均能成功运行或清理。发生收尾不明时保留隔离和阻断，不能把超时、窗口关闭或测试虚拟机销毁当作业务已经结束。

## 退出与异常

应用隐藏后可由系统启动入口重新打开；正常关闭要等待所属宿主和资源收尾。安装器在已接收的操作执行期间不会另行启动关闭请求，收到关闭回执后还会等待真实子进程退出与输出收尾。无法确认时保留窗口和阻断状态。

遇到 blocked 时保留当前诊断和事务资料。恢复只处理可核验的本程序事务，不会凭一个目录名或旧 PID 认定进程属于自己，也不承诺自动恢复任意损坏状态。
