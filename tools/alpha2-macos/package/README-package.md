# DSH SEP macOS 集成预览

本包组合 DSH 0.2.1-alpha.2、SEP 业务模块、macOS 原生运行时和独立桌面入口。它处于隔离验证阶段；打包成功本身不代表完整认证通过。请以同批 RESULT 与测试报告为准。

解压到当前用户拥有的本地 APFS 真实目录，保留整个目录结构。使用 `DSH SEP.command` 启动。内含 `.app` 是受控桌面载体，直接双击会因缺少受控连接而拒绝；Finder 直接启动仍待接入。程序使用独立 Bundle ID，数据位于当前用户的 `Library/Application Support/DSH SEP/alpha2-mac-preview`，不会接管官方 DSH 数据。

首次运行前可以选择安装目录。首次运行后，现有数据与程序身份绑定，移动程序或数据须经另行验证的受控重定位流程；本包尚未提供该流程。不要移动运行中的目录，不要单独取走 `.app` 或修改 PROGRAM.json。启动校验失败或上次收尾未确认时会阻断；请保留错误码、启动代次和数据，不要删除锁或清零账本来强制启动。

文件更改先进入受控副本，只有明确审阅并确认的计划才能提交。记忆、RAG 与预算使用独立治理记录；导入的原始文件保留，受管文档删除覆盖历史代次及待提交副本。额度变更不清零消费。

本预览使用 ad-hoc 签名，尚未取得 Developer ID 签名与 Apple 公证。当前原生沙箱只验证 macOS 15.7.9（24G830）、Apple Silicon；未验证版本拒绝该执行能力。允许创建后代的 Shell/MCP 任务不能凭父进程退出证明收尾，相关提交维持阻断。未接线的视觉、附件、AX 点击、评测和自动更新入口保持关闭。

停止使用时先正常退出，再保存需要的数据；移除程序目录不会清除上述独立数据目录。正式自动卸载、私人环境接续及完整恢复流程仍需后续认证。本包不包含私人会话、API key 或预置模型凭据。
