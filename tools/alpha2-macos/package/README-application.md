# DSH SEP macOS ARM64 隔离预览入口

本目录是 DSH 0.2.1-alpha.2 的隔离 Mac 适配预览。当前 r77 对固定 r74 应用两轮实际项目页面及正常收尾通过，r78 已将它装入新安装器并完成构建/下载；r79 独立测试入口的实际控件安装 6/6、安装后两轮启动及正常收尾审计通过，最终四文件交付已完整回读核验。请以 [当前制品与证据入口](MAC-PREVIEW-EVIDENCE.md) 为准；这些结果不代表完整 Mac 认证完成，整体仍为 `blocked`。

交付目录为 `D:\AIData\ProjectWork\DSH\alpha2-macos-package-20261014-r1\mac-preview-delivery-r1`。先使用其中安装器 ZIP 与包外 README；源码目录中的历史候选不作为当前用户安装入口。

新布局以外层 `DSH SEP.app` 为入口，由 AppKit 启动器校验固定程序清单、取得受控宿主所有权，再连接内层 Electron 桌面。不要单独运行 `Contents/Helpers` 中的桌面载体，也不要修改 `PROGRAM.json` 或 `BOOTSTRAP.json`。外层入口没有开放自定义运行目录、Node 路径或控制器路径参数。

请完整解压到本机真实 APFS 目录。数据默认建立在当前系统账户的 `~/Library/Application Support/DSH SEP/alpha2-mac-finder-preview`，与旧 `.command` 预览目录和官方 DSH 分开。首次启动后数据绑定程序身份；移动、替换或重签程序之前，需要另行验证的迁移流程。本包尚未提供原位自动升级或自动卸载。

启动与退出各有等待期限；正常长任务没有启动器总运行时限。超时不表示资源已经释放。未确认收尾时会保留隔离与阻断，请保留错误码和原数据，不要删除锁、伪造退出回执或清零预算。

受控工作副本、项目记忆、消息附件和消费账本是不同的数据域。当前项目入口针对已绑定的单个项目。文件变更先进入受控副本，提交需要绑定具体计划并形成新的受管代次，原始导入来源保持不变；额度变更不会清零原有消费。图像与文档使用独立治理入口，未授权的私人项目不会自动用于公共代码上下文准备。构建使用固定程序输入与合成测试；新安装器的限定扫描未发现覆盖规则内的凭据/状态文件，但未检查全部二进制和 ASAR，不作绝对无私人数据声明。凭据由用户自行配置。

当前测试环境是 Apple Silicon 上的 macOS 15.7.9。任意 Shell/MCP 后代进程、AX/TCC、付费模型、具体私人环境接续、物理桌面操作、Developer ID 与 Apple 公证仍须按报告逐项区分，不能由一次启动成功推断全部完成。本候选采用 ad-hoc 签名，并非已公证的公开安装版本。

固定完整应用 Profile 当前未启用普通 Shell、任务子进程或任意 MCP。安装器是另一个独立制品：r72 旧组合安装通过，r78 新组合构建通过，r79 新组合安装与安装后同库启动通过，各自绑定原始回执。原字节安装器在 36 次正常退出请求后 exit 0 并消失；其内部控制器收尾没有独立观察，不等于单击立即退出。实际控件安装来自单独测试入口，不是原字节外部鼠标输入；r77 页面证据仍不包含原生项目确认接受和实际 UI commit。

`launcher/bootstrap-ui.json` 是只用于诊断的阶段回执，不能代替租约或恢复授权。正常退出与异常后的测试清理分别记录；后续清理成功不改变先前 `blocked` 的含义。
