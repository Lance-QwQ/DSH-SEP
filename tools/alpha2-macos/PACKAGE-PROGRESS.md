## 当前实现约束

- APFS helper：1024 条目、单文件 4 MiB、总正文 32 MiB、深度 16。目录 fd、no-follow、身份与哈希复核；测试覆盖进程崩溃，不是物理断电认证。
- 文件入口：固定逻辑项目身份，实际读写受控副本；会话观察回执、候选审阅和提交分离。模型没有提交、恢复或清理权限。
- 收尾：全部已接收 API（包含只读）计入 drain；截止返回 blocked，只有真实释放才完成 whenClosed。暂时失败可重试，未知清理不因此被清零。
- 用户已选择限定 macOS 版本的原生 sandbox-exec 兼容路线。当前精确限定 macOS 15.7.9 / 24G830 / Darwin 24.6.0 / ARM64。该接口已弃用；允许 fork 的任务不能凭父进程退出或管道关闭认定后代全部结束。
- 当前 `profile/controlled-files.mjs` 的 Shell/MCP/context 路径仍明确拒绝。后继沙箱 worker 与业务组合正在开发，不能把原型通过算成已接线。
