# DSH SEP — Linux 隔离验收候选

DSH 0.2.1-alpha.2，SEP Alpha.2 适配基线。范围为专用 WSL2 / Ubuntu 24.04 x64 / ext4 的合成验证；桌面包括私有 Xorg 与 WSLg 原生 Wayland 的启动/关闭。这个本地包不代表其他发行版、真实物理桌面或完整 Linux 公开发布认证。Wayland 的表面/缓冲区协议证据不等于真实拖动、文件选择器或点击增强认证。

包含独立程序、Node、官方 Electron 入口、SEP 组合和必要字体；不含用户会话、记忆、账本、API Key。程序与数据分离。不会寻找、接管或覆盖另一个官方 DSH；安装仅接受不存在的程序目录和数据目录。需要系统 Python3、Linux 用户命名空间、D-Bus、GTK 依赖及有效桌面显示。请用普通用户运行，不要 sudo。

## 安装与启动

1. 在同一 ext4 文件系统的受控目录解包，核对提供方给出的 tar SHA-256 及 `PACKAGE.json` 中的 manifest SHA-256。SHA-256 是完整性绑定，不是发布者数字签名。
2. 创建安装请求 JSON，填写 `payload`、不存在的 `destination`、不存在的 `dataRoot` 和 `manifestSha256`。路径使用规范绝对路径，不使用符号链接。
3. 执行 `payload/node/bin/node payload/src/linux-install.mjs review request.json`，审阅计划；把返回的 `planHash` 加入请求，再执行同一命令的 `install` 动作。安装期间变化会使计划失效。
4. 执行 `<安装程序>/start.sh <数据目录>`。默认启动官方 Electron 和独立宿主；测试服务器可用 `--headless`。重复启动返回 `SEP_LINUX_ALREADY_RUNNING`，不会终止或复用无关进程。
5. 自行配置数据目录 `home/profiles/desktop/.env` 的 `DEEPSEEK_API_KEY`，或使用官方桌面凭据页面。模板默认空白；没有 Key 不等于程序文件丢失，模型服务需要有效凭据。未验证付费在线请求。

Linux 沿用 Alpha.2 官方桌面契约：欢迎页关闭会请求退出；进入主工作区后，窗口关闭会隐藏到后台，宿主与任务继续运行。要结束应用，请使用 Application → Quit（Ctrl+Q）；菜单退出才进入活动任务确认和受控收尾。Linux 候选没有 Windows 托盘入口，隐藏窗口在真实桌面环境中的重新激活尚未认证。请优先使用菜单退出；也可在启动它的终端按 Ctrl+C 请求收尾。启动器会先关闭 SEP 准入、取消所属任务、等待消费者与宿主收尾。无法确认退出时报告 blocked，不宣称资源已全部释放。正在运行时不要移动程序或数据目录。

宿主意外退出会使启动器报告 `SEP_LINUX_HOST_EXITED`，并收尾所属 Electron；不会自动重跑不确定的业务操作。所属 Electron 的 TERM 宽限为2秒，必要时 KILL 并再等待2秒；强制收尾仍报告 blocked。该路径与正常关闭不同，不包含启动器自身遭 SIGKILL、整机断电等全部故障保证。退出检查会向实际宿主查询 Agent 的运行/队列状态；当前 Profile 没有计划任务消费者，返回 `scheduledTasks:false`，不代表计划任务正例已认证。

当前 `.12` 使用外层入口、独立 Python 监督进程和 Node 三个所属进程。外层入口与 Node 同时被终止时，独立监督仍持有租约、接管孤儿后代。收到退出信号，或 Node 在等待宿主收尾前通过私有继承管道通知退出后，监督最多给 Node 40秒；届时仍未退出则定向 KILL，报告 `SEP_LINUX_OWNER_STOP_DEADLINE`，不能称为正常优雅退出。该期限不限制普通长任务的运行时长。

监督只对所属 session／被收养后代核对 UID、出生身份，并通过 pidfd 发信号；保留死亡 Node 的未回收内核身份直到收尾确认。Node 退出后，后代先 TERM、2秒后必要时 KILL；5秒仍不能确认时报告 `SEP_LINUX_OWNER_CLEANUP_UNCONFIRMED` 并保留租约，不放行重复启动。进程清单不可读同样保留租约，恢复可验证性后才继续收尾。需要 Python pidfd 接口及内核支持，缺失即拒绝启动。

诊断输出管道关闭不会中断监督清理或释放未确认租约；释放前还会核对 guardian 的直接子进程清单，不靠一次空进程快照判定完成。`MCP_EXIT_DEADLINE` 表示 MCP 已返回结果但未及时结束载具，返回失败并执行有界清理，不能据此重试外部操作。删除计划或受管代次缺失使用明确拒绝码，不把缺失当作可恢复证据。

有界回执不等于必须在截止时释放未知资源：所有权未知时保持停写是预期行为。若监督进程也遭强杀、内核调用永久阻塞或整机断电，这些规则不保证自动收尾；不按进程名称清理，也不自动重试不确定业务操作。确认可识别后代停止不等于收到全部业务优雅收尾回执。历史 `.7` 的规则只在 Node 退出后生效，不能引用为本轮退出截止的证据。

打包清单包含受控复制所需的 `snapshot-bootstrap.py`；测试专用删除中断 worker 不随程序分发。历史 `.8`／`.9` 中间包缺少该复制依赖，不能引用为安装后受控写入已通过的交付。

Linux 桌面包含一项明确的 Alpha.2 派生修复：原生退出确认通过后，将窗口销毁延后到下一次事件循环，避免本环境 Electron 44 / GTK3 的立即销毁 SIGSEGV。确认内容、取消语义及宿主收尾保持原流程；只修改编译后的 main.js 一处，来源与转换字节记录在 `desktop/SEP-LINUX-MAIN-ORIGIN.json`。不能再称桌面 main 完全未修改。

## 已接入能力

四层记忆、项目内 BM25、同项目 Mem0、自动回忆与可选捕获、按需历史展开；共享预算、单会话额度和单轮限额，默认设置不清零账本；PinchBench 与受控委派；原生图片及文本附件、数字 PDF / DOCX；受控工作副本、显式提交和恢复；只读公开 Python 静态上下文。默认自动捕获关闭。

Linux 强隔离不同于 Windows deny-write 文件句柄：Shell、文件和 MCP 在命名空间内执行，不能直接修改源项目。文件修改保留在候选工作副本，恢复后需明确选择；提交/丢弃/恢复只能由受信任控制方调用，模型没有发布权限。当前仅一个受控项目；项目树上限1024项、合计32MiB、单文件4MiB；普通工具截止最长10秒，输入16KiB、合并输出64KiB。不是无限制编译平台。外部同用户任意代码、内核漏洞和磁盘/内存配额不在保障范围。

Linux 原生评测和 AT-SPI 点击适配已包含，但默认关闭。评测需要独立准备的 Docker / SWE-bench 5.0.2、固定公开快照及绑定配置；不随包提供大型镜像或 root Docker 授权。点击需要明确的进程出生身份和辅助功能总线，限已授权应用及其子进程；不猜坐标、不开放原始派发。派发结果不确定会隔离后续点击，不能自动重试。默认 UI 不允许模型自选宿主程序或目标 PID。

本预览明确关闭原生终端、Job 控制页、PTC、系统“Open In”、workspace-changes／deliverables，以及产品遥测。它们依赖本预览不提供的原生子进程能力，不能借用无保护服务来激活。受控文件、Shell、MCP、委派及提交／恢复由 Linux SEP 自有载具提供。它不是官方 DSH 全部内置组件的等价认证。

## 恢复和更新边界

首次安装在提交记录可靠写入前不允许启动。程序发布后、提交完成前的中断，可用 `linux-install.mjs recover` 携带当前 destination/dataRoot/planHash 核对并提交；既有账本或用户数据不会替换。拷贝阶段中断保留现场，当前恢复器只接受已发布且指纹完整的程序；不要手动删除私人数据来解锁。

本候选支持独立首次安装，不是 Linux 在线更新器。尚无匹配当前候选的公网分发闭环，自动安装保持关闭。不能套用 Windows 安装器、覆盖数据目录或把另一个版本的快照还原到已有新业务写入的库。私人库导入、扫描 PDF OCR、音视频解析、真实物理拖动/托盘、全部插件和 macOS 均未据此认证。退出截止仅覆盖上述明确的请求与故障路径，不代表所有故障均可自行恢复。

包内许可证和各组件原有许可保留；Electron / Chromium、字体、Bubblewrap、各 node_modules 依赖的许可见其随附文件。公开发布前仍需完成对应平台的真实环境验收。
