# r8 尚未覆盖的交付条件

以下事项保留为 `not_run`，不把本轮范围内的通过扩大为整个 Linux/macOS 公开版已验收：

- 真人鼠标拖动、系统托盘点击、桌面菜单、macOS TCC/系统权限、真实设备上的输入输出体验。
- 官方原版 DSH 与 SEP 桌面完整并存；本轮并行的是两个独立 SEP 宿主。
- 真实自装插件、非空私人记忆库的迁移和生命周期。合成用户文件不是插件功能验证。
- 发行签名、公证、DMG/AppImage/系统快捷方式等面向用户的安装体验。Electron 上游文件的校验不能代替 SEP 应用签名。
- Electron 本身换版及其回退。本轮更新只更改 SEP 程序及精确版本绑定，验证既有 Electron 收据、载荷仍保留可用。
- 任意未经适配的官方 DSH 上直接安装 Only；仍须匹配当前明确支持的宿主文件。

本轮不替换 Windows 日常程序；不更改 main、不发布 Release。CI 安装目录用于验证，不等于已交付可长期下载的签名 macOS 安装包。
