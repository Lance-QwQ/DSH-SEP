# r7 真实桌面验证计划

固定输入为 r4 构建源码、r6 受控安装器和 Electron 44.0.0 官方载荷（使用已锁定 npm 包 checksums.json 复核）。所有输出均在 D 盘或 D 盘承载的专用 WSL 中；macOS 使用授权的 GitHub 测试分支 CI。Windows 日常版、main、Release 均不修改。

本轮验证目标：官方 Electron 压缩包摘要、真实 .app 内部链接及可执行权限；空白全量安装的真实桌面启动、页面渲染、渲染器隔离、关闭留后台、再次打开、正常退出与独立资源收尾。各平台预定三轮，全部保留；补跑另列，不覆盖失败记录。每轮启动上限 90 秒，正常退出上限 30 秒；超限记录 fail 或环境 blocked，随后只清理本轮持有的进程并记录实际路径。功能检查不计算性能开销。

采用只在测试进程启用的 localhost Inspector 驱动真实应用事件，不修改产品主入口、不开放日常调试端口；截图只来自合成空白库。无真实 API key，不发送模型请求。GUI 自动事件不能冒充鼠标拖动、真实托盘点击、macOS TCC 授权的人工验收。

本轮先验证解压载荷与既有受控宿主的直接桌面组合；它不证明发行安装包已完整携带 Electron，也不证明上游 Linux 打包脚本、签名、公证或任意官方 DSH 安装方式可用。上述事项按结果另列后续，不能降低旧标准。
