# 单会话余额安全护栏（Windows 本地候选）

本次新增“设置 → 会话预算”。金额单位为人民币；这里显示的是 SEP 按本地使用记录估计的消费上界及预留金额，不是 DeepSeek 账户充值余额或账单。

## 用法

- 默认会话上限为 100 元，可输入 0.01 至 1,000,000 元，最多两位小数。
- 修改默认值会作用于所有尚未设置独立上限的会话。
- 选择具体会话后可保存独立上限。保存时保留该会话已经发生的消费和未确认结果的预留金额。
- 同一会话的不同轮次、重复打开和恢复继续共用同一上限。被可靠绑定的子代理费用计入根会话。
- 已能核验归属的标题生成、上下文压缩等后台请求也计入根会话；不会借用当前轮次的 5 元额度。
- 旧账中缺少会话归属的记录不会被强行分配，也不会被清零；继续计入共享账本，并单独说明未归属金额。

共享累计预算（现有配置为 100 元）和单轮任务上限（现有配置为 5 元）继续独立生效。把一个会话上限设为 200 元不会提高共享预算；若共享余额不足，请求依然被拒绝。

## 生效与并发

设置保存后，对随后取得预算锁的预留请求生效。已获得预算预留的请求不会因修改设置被自动取消；它的实际费用仍会结算。降低到已计金额以下允许保存，此后新付费请求会被拦截。未知结果的请求继续占用预留，取消不能证明远端没有扣费。

设置保存使用修订号核对。其他窗口先修改过同一设置时，旧页面保存会被拒绝，需要刷新后重新审阅。设置入口不注册为模型工具，模型不能通过新接口自行提高上限。

会话单独设置以稳定会话 ID 标识。会话列表不读取消息正文；子代理不作为单独额度窗口列出。列表支持当前 Profile 的存储会话；缺少会话查询服务时只列出已加载会话。

## 账本兼容性

新代码读取 v1/v2/v3 预算账本。第一次写入旧账本前，会保存原字节 checkpoint，然后升级为 v3，保留原消费、未确认预留、子代理绑定和更正记录。新格式新增默认会话上限、单会话覆盖和修订号。

旧的仅支持 v2 的预算程序不能读取 v3。回退程序时应使用支持 v3 的恢复版本，不得用旧账本快照覆盖新消费。此候选尚未改写日常账本、日常程序或 GitHub 发布。

当前设置列表的客户端上限为 10,000 个会话，超出会明确拒绝载入；尚未实现分页。保护范围是经当前 P1 Profile 和套件受管入口处理的请求，不隔离恶意同进程插件或绕过这些入口的外部程序。
