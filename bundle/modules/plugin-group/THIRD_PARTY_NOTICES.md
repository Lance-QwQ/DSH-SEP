# Third-party components

This is the DSH SEP plugin group included in the Windows Beta source snapshot, not an official OpenClaw, Mem0, PinchBench or SWE-bench release.

- lossless-claw, Martian-Engineering, commit c84dd8cff727eff3bb6c9a26f3cf4c0510fbc343. MIT, included at vendor/lossless-claw/LICENSE. TypeScript transpiled to JavaScript. SEP-local retrieval conversation checks and the orchestrator scope forwarding are recorded in vendor/lossless-claw/SEP-LOCAL-CHANGES.md; upstream license and attribution remain intact. Only the SQLite migration/conversation/summary/token modules are exercised; no OpenClaw plugin registration or automatic compactor is installed.
- Mem0, mem0ai, commit c7ee362aff94a369af70f13f2b4f853f6793ff4c. Repository Apache-2.0 license included at vendor/mem0/LICENSE. Reused fact-extraction prompt and output schemas, transpiled from mem0-ts/src/oss/src/prompts. Not the Mem0 cloud SDK or full vector-store engine. The upstream nested OSS package lists MIT; the root Apache license is also retained conservatively. No upstream telemetry or external database is invoked.
- PinchBench skill, commit 819384ae830492365b8363fc26bc2602e73f216d. MIT license at vendor/pinchbench/LICENSE. vendor/pinchbench/selected-sources.json binds three included task references. source/prework.mjs uses an explicitly synthetic local adaptation with a new deterministic grader; upstream graders and external-action tasks are not executed. No leaderboard upload or claim of official scores.
- SWE-ReX and SWE-bench: this plugin group includes read-only authenticated HTTP liveness and prediction-record formatting adapters. The separately packaged trusted-evaluation-entry owns the governed backend lifecycle. The old statement that execution remained pending described the original adapter preparation stage; current tested-instance coverage is stated in the release verification report. No claim of comprehensive repository or problem compatibility follows from those fixed-instance tests.

The original upstream/sources.json and external evidence index were preparation-workspace locators and are not included here. Included upstream commit pins are listed above; vendor/pinchbench/selected-sources.json binds the three reference files, and vendor/lossless-claw/SEP-LOCAL-CHANGES.md records local modifications. The release source manifest independently binds every included file. Native Node.js SQLite is used only in a bounded temporary Worker with an in-memory database. This build does not create private persistent memory files.
