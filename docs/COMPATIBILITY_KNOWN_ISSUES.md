# 兼容性与已知限制

本版是 **SEP 0.2.1-beta.1 / DSH 0.2.0-rc.2 / Windows x64 Beta**。本版内容目录安装、受控更新和真实首启已限定通过；四份最终归档的CRC、SHA-256、脱敏与ZIP安装结论由随资产提供的包外 `ARTIFACT-VERIFICATION.json` 和 `SHA256SUMS.txt` 权威记录。内容验收见 [VERIFICATION.md](VERIFICATION.md) 和 [机器结果](VERIFICATION-RESULT.json)。

## 系统与安装

Windows 10／11 x64为目标范围；本机Windows证据不保证全部硬件、ARM64、组织安全策略或特殊文件系统。Linux WSL与macOS CI已有限定运行／回归证据，但没有完成本版完整桌面发行、权限和交互验收，不能把Windows包移植后直接称支持。

Full／Only均在尚不存在的真实目录安装，内部链接绑定该位置；安装后移动目录不是受支持迁移。Only要求精确官方npm来源，不是任意版本号相同的官方桌面补丁。来源官方DSH保持原样；用户主动选择共享工作目录时仍可能操作同一文件。

## 保护范围

| 功能 | 当前边界 |
|---|---|
| 标准文件保护 | Windows x64原生恢复后端；显式要求保护时不足即拒绝。POSIX普通入口可运行不等于SEP保护能力全面跨平台。 |
| Safe Change | 一个现有UTF-8文件、有界候选、分项内容／语法验证；运行测试执行器尚未提供，不是项目构建沙箱。 |
| 子任务 | 最多两项、两次返工、超时／取消／记录限于`suite_delegate`创建的任务。 |
| RAG | BM25本地文本索引；多硬链接、符号链接或身份无法核验来源拒绝。扫描PDF、音视频不因文本提取而完成理解。 |
| 点击增强 | 需要受信Windows MCP和语义目标；不能保证无UI Automation控件可点击，不拦截底层原生/MCP直调。 |
| 更新评估 | 默认关闭的模型分析与复核，可能收费，无安装权限，无运行兼容认证。 |
| SWE评测 | 默认关闭，需要另配专用后端；固定SymPy／Flask正负对照不等于完整兼容／榜单或在线模型正例闭环。 |
| 实例隔离 | 程序、配置、数据、锁及所属进程独立；不是恶意代码安全沙箱。 |

## 数据兼容与恢复

- 预算v3可读取旧账后checkpoint迁移；旧预算程序未必读取v3。不得用旧账覆盖新消费或未知预留来回退。
- P1历史不再以200条硬限制截断，默认16MiB受检写入容量、可配置1–64MiB；旧程序可能拒绝超过200条历史。同schema号不保证旧语义兼容。
- JSON后端仍会读取整项目，字节写入限额不是对任意既有超大文件的读前内存硬上限。
- 旧orphan／prepared备份不自动删除；已经配额满的旧库须逐项受控核对。
- 源库身份、写者退役、治理覆盖和删除依据不明确的旧库不自动纳管。合成纳管通过不代表任意私人旧库直接可升级。
- P2验证完整journal后可对账旧head，不清未决意图、不重放副作用、不清维护屏障。缺权限依据／损坏尾部仍阻断。
- 未绑定维护事务的普通取消出口、guardian底层无响应回调的完整取消生命周期仍有专门验证边界；不能通过清屏障宣称自修复。
- 超时和取消不证明远端没执行／没扣费。未知外部副作用、未知点击和未知预算预留不得盲目重试或释放。

## 来源与完整性

选择新版或接受unknown风险不豁免完整性和保留门禁。公开Beta.2宿主0.1.7-rc.2不支持本版同宿主差分直接跳0.2.0-rc.2；详见 [UPDATE-SCOPE.md](UPDATE-SCOPE.md)。

完整lossless-claw编排器未接入私人流程；其未启用完整模块仍有依赖／接线边界。当前集成是选定来源模块、原生压缩及受控展开，不能宣传为完整持久化多级“绝对无损”引擎。Mem0也不是完整云／向量库。

维护回归中的Windows symlink权限夹具和原SDK旧golden差异保留，不能泛称全仓CI通过。全仓100%覆盖、原生二进制逐字节重建、多日压力、真实断电及全部私人插件尚未证明。

历史B子任务快速失败未归因，后续固定样本通过不证明原原因消失。历史宿主启动异常按各图的修复／未复现记录区分，不能用新包成功反改旧报告。最终未知兼容数取决于本包；旧日常875行只表示当时盘点证据不足。

Office预览沿用受信本地转换适配器和随包运行库；字体完整性自动诊断不可用，格式／分页不保证与Microsoft Office完全相同。源／临时路径过长或不支持配置会明确拒绝，不能手改全局盘符或移动实例规避。实际依赖版本以本版清单为准。

## 本轮桌面非致命诊断

真实Electron首启12项检查中观察到 `No handler registered for 'dsh-desktop:mandatory-status'` 控制台警告。空白Key欢迎页及跳过操作、主界面和SEP品牌正常，正常app.quit后无所属残留。本轮没有修复或证明官方mandatory通道正常；SEP受控更新路径已另外验证，不能用这一路径成功代替官方通道验收。

早期桌面探针因未处理欢迎页或等待错误URL超时，更新探针曾因schema／旧revision不符被正确拒绝；失败保留，不归为已证明的产品不稳定。最终ZIP验收以包外归档凭证绑定的实际归档字节为准。

BM25算法参数、中文分词、JSON数据域与SQLite辅助组件的区别，以及记忆生命周期和费用边界，见[技术概览](TECHNICAL_OVERVIEW.md)。

BM25当前没有Embedding或持久化倒排索引，大规模吞吐、跨语言和隐含语义召回不在本版保证范围。中文双字组合可能跨原标点或非汉字间隔；这是当前实现细节，不是已完成新的分词修复。
