## Office 替换组件的兼容范围

自带官方 LibreOffice 26.8.0.3，约 1.58 GB 解压后运行库；无需全局安装。目标 Windows 10/11 x64，功能基线实测 Windows 11，其他系统不据此标 pass。支持范围和固定合成样本见 [Office 转换说明](OFFICE_CONVERTER.md)。

Office 的独立 profile／任务临时目录要求传给引擎的原路径或同目录可核验的 Windows 8.3 短名称不超过 128 个 UTF-16 字符。没有合格短名称时启动前明确拒绝，需改用较短的可写转换工作目录；不会自动创建全局盘符或改写磁盘设置。128 是适配器的保守支持边界，不是通用 Windows／LibreOffice 极限。v1 长 profile 的 18 个失败样本保持失败，v2 的实际补测状态见测试摘要。

CLI 后端无法返回可靠的缺失字体列表，`fontDiagnostics` 为 `unavailable`，界面必须提示；`missingFonts: []` 不能解释为字体检查通过。自定义 `fontDirectories`、`fontFallbacks`、`initialFontFamilies` 和非默认字体数量／字节限额不支持并报错；默认字体限额字段仅兼容上层传参，没有对 Windows 字体系统实际执行这些上限。格式、排版、字体、分页和高级对象不保证完全等同 Microsoft Office。


本版用 **SEP 自有 Office 转换适配器＋官方 LibreOffice 26.8.0.3** 替换缺少可核验 Node API 源码入口的旧 Kit。匹配的四份官方源码归档已完整下载并核对 SHA-256；旧 Kit 的 404 记录属于历史包问题，不再是本版该组件的源码入口。新实现和包级结果见[Office 转换说明](OFFICE_CONVERTER.md)及[测试摘要](TEST_ACCEPTANCE.md)。

历史 `GUARDIAN_NOT_READY`／`HOST_STARTUP_UNATTRIBUTED` 宿主启动异常仍未归因、未证明修复；原 Only 合成安装追加的 10 次启动、记忆只读检查和正常退出均未复现。项目所有者已允许带此已知问题进行 Windows Alpha 测试发布。这项决定不把历史 fail 改为 pass，不降低原验收标准，也不表示通过稳定版准入。

更新日期：2026-09-21。定位为 **Windows x64 适配版 / Alpha 测试发布**，不能从本页推导为全环境稳定版认证。SEP许可已确定，见[许可说明](LICENSING.md)；本次 Alpha 分发按文件权属同步许可；第三方材料与最终包核验按本轮实际证据记录，见[发布检查表](PUBLICATION_CHECKLIST.md)。

## 当前功能边界

- 自动记忆使用现有四种 Agent 模式的设置项，没有单独的第五种模式。Mem0 是同项目提炼适配，未安装完整 Mem0 云存储；lossless-claw 是来源完整性和受控原文展开适配，不是完整持久化多级 LCM 引擎。
- 工作前评测是 PinchBench 思路的本地合成就绪筛查，固定三轮且每轮达到既定 0.8 门槛才放行。它不是官方总分、复杂任务质量保证或风险操作授权。历史未归因的 `PREWORK_EXECUTION_BLOCKED` 样本仍保留；后来通过只说明未复现，未证明原因已消除。
- “最多两个子任务”、最多两次返工以及统一超时、取消、记录规则限定为**经 `suite_delegate` 创建的任务**。Profile 级模型与预算拦截是独立机制。其他插件、原生递归任务与普通 Shell 不自动取得相同生命周期保证。
- Safe Change 是单个已有 UTF-8 文件的候选、静态检查、审阅与确认发布流程。不是所有文件写入口的全局拦截，也不是完整构建测试沙箱。未配置运行测试时会拒绝 `runtimeTest`，不能把语法检查当作行为测试。
- SWE-bench / SWE-ReX 及受信任评测入口默认关闭，需另行配置受控 WSL / Docker 后端。固定公开 SymPy 与 Flask 实例已有正负对照；不能扩展成任意仓库、问题类型或真实模型正例均通过。
- 日常主模型、子任务、输出、请求体和预算均有上限；上限分离修复不保证无限长任务。HTTP 超时可能意味着结果未知；不能据此盲目重放有副作用操作或释放费用预留。
- 首次私人旧库纳管仍需要确认具体目录、写者与治理范围。合成纳管通过不意味着可以把任意旧库直接挂进受控更新器。未知治理覆盖、删除依据缺失或无法证明写者退役时保持阻断。
- 自动恢复只作用于已登记实例及可验证身份。桌面等待守护恢复上限 60 秒；身份不符、守护熔断或不能证明旧所有者已退出时停止自动等待。不会恢复所有外部进程，也不会自动重放未知副作用。

## 更新可做什么，不能跳过什么

当前日常修订恢复了打开时、运行每三小时及手动官方版本查询，保留“立即更新 / 暂不更新”和全插件兼容清单。检查本身不消耗模型 token。排队安装须等待所属桌面完整退出；只隐藏窗口不满足这一条件。

报告覆盖已登记包图、额外安装包与插件实例，包含禁用项。静态依赖、来源和指纹满足不等于运行兼容；未知项仍列为“未验证”，不能把清单条数当作全部插件通过数。用户可接受列明的兼容性风险，但不能跳过：候选缺失、来源基线或完整性无法验证、插件保留失败、维护锁、治理覆盖、恢复依据和提交条件。

只有已准备并批准、与计划和健康证据绑定的本地候选才能安装。查询到新官方版本不会自动产生兼容的 SEP 候选；包名前缀也不能证明文件可覆盖。用户自装插件、配置和数据不通过静默删除或禁用来获得“兼容”。尚无任意上游版本自动适配、构建和认证服务。
