## 相较公开 Beta.2

公开 Beta.2 的宿主是 DSH 0.1.7-rc.2。本版包含新的 DSH 宿主及 SEP 接线，变更不限于点击插件，也不是仅修更新提示。审阅应包含宿主改动和全部 SEP 包；子包 local.* 版本不能代替套件版本。

主要改动：

1. **预算与会话恢复。** 本地预算区分共享累计、可信根轮次／其子任务、会话累计限制。设置页提供默认100元及会话独立上限，不重置消费和未确认预留；账本缺失不会静默新建空账本。
2. **文件与后台工具。** 原生文件入口在未要求恢复保护时恢复其跨平台默认契约；显式保护仍强制检查。Worker 源码／打包入口和必要产物同步，保留实际调用证据。不透明 JobId 的关联契约与子进程终止测试同步。
3. **持久化与恢复。** 验证完整 P2 journal 后，允许对确为已发布前缀的旧 head 进行对账；不重放业务操作、不清空维护屏障。守卫拒绝不再新建永久 prepared 备份。内部评测文件完整性清单与实际文件重新绑定。
4. **记忆与受管任务。** 文档归档不再误阻断无关对话来源；P1 历史改用受检字节容量与分页，保留旧记录。用户取消工作前评测不缓存成24小时失败；仍保留实际失败结论。
5. **文件修改工作流。** Safe Change 的可信按钮确认绑定会话、候选、修订和期限；文本、语法、运行测试分开报告。当前没有运行测试执行器，不将语法检查当作行为验收。正常收尾摘要不额外请求模型。
6. **可选后台适配评估。** 发现官方 DSH 新版后可执行分析和证据复核，默认关闭；按本次后台任务额度和共享预算限制费用。相同证据已尝试的记录不因启停或重启自动重跑。模型报告不具安装资格。
7. **更新提示。** 区分部分清单缺失、全部缺失和无公开发布。已核验清单中没有更高版本只代表该范围；网络、来源、哈希和内容异常仍为错误。
8. **桌面集成。** 保留一体式顶部、SEP 标识、后台运行和独立实例启动；修复桌面构建混入源码及设置页长文本溢出。窗口关闭不等于完整退出。

## 审查如何处理

Kimi 审查包含独立复现成立的问题、测试／文档契约不同步及需要更正的归因，不能统一称为“16个漏洞均修复”。正常 Worker 返回路径未复现其所称约半数失败；提供方伪造 rendered 在实际 execute 路径被丢弃并重新渲染。授权原语保留“会话内空 summary 列表”的明确语义，同时补会话及消息归属核验。新回归锁定这些边界，不以推测归因替代证据。

## 更新和数据

本版更新包只接受 [UPDATE-SCOPE.md](UPDATE-SCOPE.md) 的精确同宿主基图。公开 Beta.2 跨宿主升级、未知版本及改过程序字节的环境不得通过该差分。用户插件、私人数据和账本不作为更新载荷；不以清空数据或禁用用户插件获得“兼容”。

预算v3及超过旧200条限制的工作流历史可能无法由旧程序读取。相同 schema 号不足以证明旧代码兼容，不得用旧快照覆盖新消费或工作。[已知限制](COMPATIBILITY_KNOWN_ISSUES.md)列明保留边界。

真实桌面冒烟观察到非致命 `No handler registered for 'dsh-desktop:mandatory-status'` 警告，主界面正常。本轮没有修复或证明官方mandatory通道可用；SEP受控更新路径有独立验证，不能互相替代。
