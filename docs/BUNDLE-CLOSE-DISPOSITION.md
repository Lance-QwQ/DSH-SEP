# 第7步：历史关闭异常的有限结论

有限调查与归档为pass，历史问题仍未归因、未证明修复。本阶段不再增加实验。之前已执行6个诊断样本：100ms关闭与700ms挂载失败路径各3次，完整输入、时间线与原始失败日志均保持。

100ms路径三例均先在模型仍挂起时返回blocked，明确保留资源；显式释放模型门禁、等待模型结束后再次关闭，实际租约关闭且whenClosed完成。最终锁消失是后续受控收尾证据，不能倒推第一次blocked已清理。挂载失败三例同样在恢复门禁未释放时保留资源，解除门禁后才完成关闭/处置。

用户批准的测试观察修正保留：100ms限制本次close回执，真正关闭另以whenClosed和有限3s夹具期限观察；700ms从故障注入起算，冷启动单独5s。生产截止未变，没有延长测试来掩盖实际无界退出，也没有把全部历史慢样本归因变成永久门槛。
