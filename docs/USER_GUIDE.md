# 使用手册 · Windows Beta

[导航](DOCS_INDEX.md) · [安装](README.md) · [限制](COMPATIBILITY_KNOWN_ISSUES.md)

本手册对应 SEP 0.2.1-beta.1 / DSH 0.2.0-rc.2。本版内容目录已完成限定安装、更新及桌面首启验证，见 [内容验收](VERIFICATION-RESULT.json)。四份最终归档的CRC、SHA-256、脱敏审计和ZIP安装结论由随资产提供的包外 `ARTIFACT-VERIFICATION.json` 和 `SHA256SUMS.txt` 权威记录。所有示例数据为占位，不应把内部 JSON／SQLite 当作普通文档直接编辑。

## 启动、后台与插件

安装后使用该实例的 `start.vbs`。它会拉起所属宿主；实例独立，不去启动或关闭另一个官方 DSH。关闭窗口保留后台，完整退出用应用或托盘“退出 DSH SEP”。不要按 node／electron 名称批量杀进程。

SEP 由多个 Cordis 插件和必要宿主适配组成，部分能力默认关闭或需要后端。包存在不代表每项服务都已启用。卸载一个独立 SEP 实例不修改来源官方 DSH；不要直接从组合实例删掉 vendor／node_modules 来模拟卸载。

## 记忆增强

进入 **设置 → 记忆增强**，选择当前项目。自动学习和自动引用分别控制后续提炼与注入，不删除已有记忆，也不撤回已发送请求。提炼可能调用模型并计费；以存储回执为准。

| 层级 | 内容与使用 |
|---|---|
| L1 | 模型自身上下文窗口，无额外持久化库。 |
| L2 | 本项目资料、任务和临时事项，选择相关有效内容。 |
| L3 | 用户习惯、明确重要事实、项目总目标；个人资料仅在显式同用户共享配置下跨项目共享，目标仍按项目。 |
| L4 | 归档历史，普通检索不强制访问；用户明确提出追溯、历史或恢复需求后按需查阅。 |

Mem0 适配只取当前注册项目、当前会话当前轮次选中的直接用户消息，不扫描其他项目或全部历史。共享 L3 规则不等于跨项目聊天访问。

有明确完成／取消时间的任务满7天，未确认候选和无有效使用的临时事项通常满30天，结束项目目标满30天且无未结任务，可按条件归档。置顶、保留、依赖、冲突、无效时间等阻止归档；普通扫描和自动注入不刷新活跃时间。归档保存正文，不等于删除。

当前活动目录有记录数和字节上限，不是无限存储。达到门禁应受控整理，不手工删除内部 JSON。设置页提供开关和状态，尚不是全部正文的图形编辑器。

## 本地 RAG 建库

初始项目默认授权 `workspace/knowledge`。新注册项目默认没有文件来源，也没有共享用户配置；需要受控授予来源，不能因在对话中提到路径就越权扫描。

把支持的普通文件放入授权目录，要求 Agent 调用：

```text
suite_index({})
suite_search({"query":"部署要求","limit":3})
```

这是 Agent 工具及 JSON 参数，**不是 PowerShell 命令**。本地解析文本、Markdown、CSV、JSON、文本 PDF、DOCX，按行／页／段落分块。使用 **BM25 文本检索**，当前返回 `embedding:null`，无需外置向量库；解析文件不等于把整个资料库发给模型。选入模型上下文的片段仍会发送给实际配置的模型服务。

单来源上限8 MiB、一次语料32 MiB、最多5000块；检索最多5项，正文累计最多6000字符。符号链接、多硬链接或无法核验本地身份的来源拒绝。扫描 PDF 不等于已有 OCR，音视频和图片走各自能力。

先用正常编辑器修改源文件，再重新 `suite_index`。旧正文可转归档；移走文件不等于永久删除历史。结构化记忆更正使用 `suite_memory_revise`，永久删除用 `suite_memory_purge`，均应先读取实际ID与修订。

文档删除先预览：

```text
suite_document_delete({"action":"preview","path":"knowledge/旧说明.md","deleteSource":false})
```

检查返回范围后，按工具给出的**确切确认句**确认；删除原文件须在计划单独选择。中断先查 `status`，不能重造计划绕过未决事务。只有 `cleanup.complete:true` 才代表该计划范围清理完成；原生聊天、外部副本、供应商已收内容不在全局抹除范围。

## 会话预算

进入 **设置 → 会话预算**：

- 默认每会话100元；可调整默认值或给具体会话独立上限，范围0.01至1,000,000元，最多两位小数。
- 保存保留已发生消费、未知预留与修订。新上限对随后取得预算锁的请求生效；不自动取消已获预留的请求。
- 降至已计金额以下允许保存，后续新付费请求被拒绝。
- 会话累计、共享累计预算与可信根轮次／其子任务额度分别检查。会话设高不提高共享余额。
- 恢复、重开会话或新轮次不清零。已可靠绑定的后台与子代理请求按根会话记账；未归属旧账仍留在共享账本。

金额是本地消费估计及未知预留，不是 DeepSeek 充值余额或提供方账单。预算不足后先停止／取消当前执行，检查本地状态；不删除账本“解除错误”。未知远端请求不能仅因取消释放预留。已有账本缺失会明确阻断，不自动新建空账本。

## 受管任务和文件修改

最多两个只读子任务、最多两次返工、超时、取消与记录规则，**仅限经 `suite_delegate` 创建的任务**。Profile级模型许可、请求限额及预算检查是另一层机制；不扩展为全部原生子代理或Ralph循环。

PinchBench参考的工作前评测是固定合成就绪检查，会调用模型；不是官方榜单或复杂任务质量保证。普通取消不缓存为失败，真正评估结论按原绑定和期限保存。

Safe Change 流程为 `prepare → stage → verify → review → publish`，针对一个已有UTF-8文件。有可信按钮或当前用户确切计划文本确认；模型自写“已批准”无效。候选变化、过期、权限或文件身份变化要求重验。文本、语法与运行测试分开报告；当前要求运行测试会返回 `SC_RUNTIME_NOT_CONFIGURED`，语法通过不能称行为验收通过。普通已授权可回退编辑不一概要求重复确认；普通 Shell 不会自动进入沙箱。

## 更新与后台评估

侧栏底部按相同样式分别显示 SEP／DSH 更新入口，SEP 位于 DSH 上方；是否出现取决于发现状态。也可从应用菜单检查更新。默认在启动及运行每3小时查询发布；**发布查询本身不消耗模型token**。

“已核验清单未发现更高版本”只说明已验证范围，历史缺清单会单独提示。发现官方新版不等于已有可安装适配包。缺候选或硬阻断不能通过风险确认跳过。

进入 **设置 → 更新适配评估**，开关默认关闭。开启后，官方DSH新版的公共说明与本地插件静态摘要可触发分析、复核两阶段模型请求，产生token及费用；额度与共享账本同时生效。模型不获得工具权限，不修改代码，不授权安装，结果仍为 `installable:false`。手动重试是新的可能收费尝试，启停／重启不会把已有消费清零。

费用面板分开显示已报告tokens、估计费用和未知预留；无usage显示“尚未报告”。停止本地等待不证明远端停止收费。[更新范围](UPDATE-SCOPE.md)说明真正安装门禁。

## 点击与评测

Windows语义点击插件默认关闭，需要已安装且受信任的Windows MCP及匹配服务名。增强工具根据已观察的窗口／元素身份操作，不用坐标猜测；返回最小状态，不把UI树正文塞入模型上下文。不确定是否已派发的点击不自动重试，提供方未确认停止时保持隔离。

SWE-bench／SWE-ReX受控入口默认关闭，需要专用Linux／容器后端；包内接口不等于完整运行时已一键安装。两个固定公开实例的后端正负对照，不代表任意仓库或在线Agent解题都通过。

BM25算法参数、中文分词、JSON数据域与SQLite辅助组件的区别，以及记忆生命周期和费用边界，见[技术概览](TECHNICAL_OVERVIEW.md)。

检索偏向出现相同词项的片段；同义改写未命中时先使用资料中的关键词，并检查是否需要重新建库。BM25分数不表示事实可信度；模型提炼和将结果注入模型上下文仍可能收费。
