# DSH SEP是什么？

**DSH SEP是在DeepSeek Harness上组合记忆、任务管理、文件修改、更新与恢复能力的系统增强套件。**

本版是 **SEP 0.2.1-beta.1 / DSH 0.2.0-rc.2 / Windows x64 Beta**，已完成限定内容目录安装、更新与真实桌面验证；四份最终归档的CRC、SHA-256、脱敏审计和ZIP安装结论由随资产提供的包外 `ARTIFACT-VERIFICATION.json` 和 `SHA256SUMS.txt` 权威记录。本版不是SEP RC或三平台桌面稳定版。[安装入口](README.md) · [完整导航](DOCS_INDEX.md)

## 相较DSH的核心亮点

**项目工作更连贯。** 四层记忆把当前上下文、项目事项、长期习惯和按需归档分开。本地BM25 RAG提供来源定位；Mem0辅助提炼只取当前项目允许的直接用户消息。

**费用更可见。** 默认每会话100元护栏可调整；共享累计与单轮任务额度仍独立检查，恢复和重开不清零。已计消费、未知预留与提供方账单分开说明。

**修改更可审阅。** Safe Change展示确切候选，绑定可信确认，区分文本、语法与运行验证；正常收尾保留实际失败和未覆盖项。普通Shell不承诺全局沙箱保护。

**任务更有边界。** 经`suite_delegate`创建的任务具备受管并发、返工、取消与记录；工作前合成筛查不冒充复杂任务能力认证。

**更新更受控。** DSH与SEP分别发现版本、列出插件兼容信息和确切计划。可选后台分析与复核默认关闭，开启会计费；模型结论不能直接授权安装。

**故障更可追溯。** 已登记实例通过身份、程序／数据绑定及提交记录恢复；不确定的外部操作或点击不盲目重试，不以清空旧数据“恢复成功”。

Full提供完整新实例；Only保留SEP和必要适配，从精确官方npm来源创建新实例。两者保留来源官方DSH，不是原地覆盖，更不是操作系统安全沙箱。
