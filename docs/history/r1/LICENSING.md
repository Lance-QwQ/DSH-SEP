项目所有者已于 2026-09-21 确认：**允许个人及企业内部使用、修改、转发和制作衍生版；出售或商业分发须另行授权，衍生版沿用相同商业限制。** 正式条款见 [LICENSE](LICENSE)，名称为“DSH SEP 限制商业分发许可 1.0”。本页是说明，具体授权以许可正文为准。

## 常见情形

| 行为 | 当前许可 |
|---|---|
| 个人安装、运行、修改 | 允许。 |
| 企业在内部业务中安装、使用、修改和部署 | 允许，不因内部业务具有商业目的而禁止。 |
| 免费转发原版或发布衍生版 | 允许；保留署名、版权及许可，说明修改；衍生版保留相同商业限制。 |
| 出售原版、收费许可或有偿交付衍生版 | 须取得相应权利人另行授权。把软件作为收费产品的交付部分也受该限制。 |
| 企业免费转发 | 企业身份本身不构成禁止；仍须符合转发条件。 |
| 利用 SEP 形成独立的业务成果 | 不因使用 SEP 而受上述软件分发限制；成果含有 SEP 或其衍生代码时，所含部分仍受约束。 |
| 咨询、培训、赞助等活动 | 不因活动名称或收费本身自动禁止；按是否实际出售、收费许可或有偿交付软件判断。 |
| 衍生版源码全部公开或向原项目提交修改 | 本许可没有额外强制这两项义务；第三方许可另有要求的，按其要求。 |

衍生版沿用商业限制，不等于把独立的第三方组件也改为 SEP 许可。DSH、Electron、Cordis、Mem0 等第三方部分继续按各自原许可处理；不撤销接收者此前依有效许可取得的权利。
