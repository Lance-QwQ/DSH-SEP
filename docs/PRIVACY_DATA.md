## 本地数据

安装根下分别存放程序、运行环境、`home` 会话／设置、受管 `data`、`state` 锁／更新恢复资料、`workspace` 文件及本机 `.env`。实际位置可由受信配置改变，不能仅凭目录名推断删除范围。

记忆和RAG保存在受管本地存储；索引是文本检索，不要求Mem0云或外置向量数据库。预算账本保留消费、预留和更正；可选适配评估SQLite记录位于其配置的预算账本旁。不要将这些内部文件当普通知识文档纳入索引。

项目过滤不是防恶意同进程代码的安全边界。普通Shell与用户自装插件拥有其实际进程权限，独立实例不等于操作系统沙箱。

## 什么时候向外发送

| 触发 | 可能发送内容 |
|---|---|
| 正常模型请求、摘要或自动记忆 | 当前实际选入的对话、工具结果、资料／记忆片段，按模型配置发送。 |
| Mem0辅助提炼 | 当前注册项目、当前会话当前轮次选中的直接用户消息；不取其他项目、工具消息或L4正文。 |
| 原生图片／`suite_vision` | 获准图片及提示，按模型能力和预算执行；不宣称一律离线。 |
| 工作前评测 | 固定合成题与提示，会调用模型并计费，不上传官方榜单。 |
| DSH／SEP版本查询 | 公共发布请求及通常连接信息，本身不调用模型。 |
| 用户开启的更新适配评估 | 有界公开发布说明、包名／版本／静态状态和原因码；不发送本地路径、配置值、Key、对话、记忆或项目文件。 |
| 用户启用的MCP、搜索和其他插件 | 由相应工具实现及输入决定，不由Mem0项目过滤统一保证。 |

关闭学习／引用只影响后续行为，不撤回既有模型请求。供应商已接收的数据不因本地删除而自动消失；供应商的留存、地域与账号政策需自行查看。

自动适配评估默认关闭；开启允许两阶段付费请求。取消会停止后续派发及本地等待，已发请求仍可能计费；实际usage继续结算，未知结果保留预留。

## 删除、归档和纳管

归档仍保存正文。结构化记忆更正／永久删除和文档删除走受管工具及精确计划；删除依据不会跟随旧快照回退。缺删除依据或归属无法核验时停止恢复。清理未完成显示pending，不等于全部副本已删。

旧私人库首次纳管要求明确来源、所有写者与退役机制、作用域和治理覆盖。正文审阅、预览、捕获、暂存与失败现场的新副本也受记录和清理规则约束；原库保留安排单独说明。导入保留可解释的原创建、更新、有效使用、完成和到期时间，独立记录 `adoptedAt`；用户审阅不刷新保留期。

首次纳管新增受管正文副本按固定24小时规则处理，运行中的TTL工作器会检查；被占用或恢复证明不足仍保留pending。终止且正文已清理的普通准备元数据通常保留30天；治理、首基线、删除依据及恢复引用记录例外保留。该规则不扩展为所有会话、L4、预算、更新候选或外部备份均自动清理。

原生聊天、助手复述、第三方副本、用户导出、外部备份和供应商内容不属于记忆删除的全局擦除范围。逻辑删除也不是取证级物理擦除。

## 更新与反馈资料

本地更新审阅、配置副本、checkpoint和故障现场可能含私人路径／内联设置，不能当公开发布资产。未决事务须保留；不要为腾空间删除恢复依据。

反馈优先提供合成复现、版本、错误码和经脱敏日志。不得发送 `.env`、认证头、Cookie、Key、私人会话正文、内网地址、用户名和工作区内容。程序完整源码分发不含私人Git历史；公开来源记录只绑定项目代码和分发材料。
