# Beta.2 验证范围

## 本轮修复候选

37 项定向检查通过，统计口径为 27 项 P1 单元检查、4 项真实组件组合检查和 6 项预算回归。正例覆盖用户/工具图片、历史图片后的文字续接、重复出现逐项预算、卸载占位、原限制保留，以及能力查询期间取消/停用。负例覆盖无图像能力、能力或计量缺失、预算不足及既有模型/输入/输出限制。

真实组合从 Cordis Loader 启动 Agent，执行原生 `read_image`，使用原生附件服务与 DeepSeek Messages 适配器，再由全新 JSONL reader 核对持久化结果。外部服务由本地 HTTP 录制响应代替；Files 返回合成 404，随后走真实 inline fallback。三轮固定正例和一个无图模型负例不等于在线视觉理解、全部图片场景或所有插件已通过。

## 新公开分发包

Full / Only / Update / Source 的分发检查与上述修复候选分开记录。公开源码将新增测试的 Host 图锁重新绑定到本次公开 Beta.2 图；这是测试元数据适配，未改生产行为。新包的安装、完整性、回归与资源检查以本次发布验证记录为准，不从 Beta.1 的成功结果直接推导。

## 历史证据

Beta.1 已有原生 GUI、手动拖动/托盘辅助、另一台 Windows、Full / Only 安装及既有回归证据。本次保留其原范围和日期，没有将它们重新标作 Beta.2 新测。手动协助不等于全自动 UI 验证，短时固定场景不等于多日高负载稳定性。

## 尚未证明的范围

未自动继续原私人长任务，未进行本轮付费在线视觉理解，也未逐项执行所有私人插件、外部 MCP 或任意多模态材料。兼容性未逐项验证记录不是已确认故障；具体用户环境仍需自身适配审阅。`metadata-unavailable` 状态提示和部分异常结构化 `UNKNOWN` 仍是已知限制。

## 最终公开包的本机验证

本版公开 Source 的实际测试入口对最终 Full 安装图执行 **37/37** 检查（27 + 4 + 6），测试图和生产文件绑定到下列目标图。Full 与 Only 都完成全新目录安装，各执行三轮真实 Host 启停、两个工作区的记忆设置与重启保留检查，所属 Host 正常退出。Only 的五个拒绝场景通过：不支持的版本、缺失来源、同版本字节被修改、目标已存在、源与目标重叠。原官方来源的前后快照一致。

从公开 Beta.1 的实际安装执行精确基线差分准备、空白健康检查、三域发布至 `committed`、业务入口开放及新 Host 启停。合成用户文档、空白 Key 文件、记忆偏好，以及合成停用插件入口文件的字节、链接及预设配置字段保留；数据指纹与业务序号一致。该停用插件没有执行，不能据此声称任意第三方插件运行兼容。已提交恢复检查和错误基线拒绝亦保留记录。测试中的计划同意仅用于隔离合成实例。

每个安装检查了 47,938 项程序文件；公开 Source 中 117 项直接映射、7 项发布变更、4 项版本绑定均与程序一致。Source ZIP 的 14,318 个文件与本版 Git 目录逐字节一致，无额外源码例外。归档校验与限定模式的隐私审查没有发现未解释的命中；上游合成测试常量与旧公开版逐字节对应，这不等于数学证明所有格式的秘密都不存在。

发布准备中先前失败单独保留：Windows 测试启动器错误传入普通路径；程序图顺序变化触发插件字节保护；归档核验脚本误用另一 ZIP 的条目对象。分别修正测试入口、保持基线清单顺序和核验脚本后，才对最终图验证。没有放宽更新门禁，7 项生产变更未因此追加或改写；失败日志不并入通过项数量。

本轮未重跑原生 GUI、另一台 Windows 或付费模型。安装轮数、测试项数与交易场景分别统计，不能相加后当作全部能力验收。
