# DSH SEP 0.2.0-beta.1 — Windows Beta 测试版

DSH SEP（DEEPSEEK HARNESS SYSTEM ENHANCEMENT PACKAGE）为 DeepSeek Harness 增加项目记忆、本地 RAG、受管任务、受控更新、故障恢复与点击辅助。本版基于 DSH 0.1.7-rc.2，仅声明 Windows x64 测试范围。SEP 原创部分采用 MIT，DSH 和第三方组件保留各自许可。

## 主要变化

- 将本地已验证的 local.8 增强集合正式绑定为 SEP 0.2.0-beta.1；Beta 打包阶段只调整版本与依赖绑定，不借版本升级宣称新的功能修复。
- 相较旧公开 Alpha，纳入 rc.2 宿主适配、分别面向 DSH/SEP 的更新入口、工作区记忆作用域修正、提问窗口链路修正、点击观测最小化与异常提供方有界等待、兼容性来源盘点及受控切换改进。
- 关闭主窗口保留后台，可从托盘恢复；完整退出使用应用或托盘的退出命令。

## 已有证据与限制

Full、Only 分别有三轮真实 Host 测试；另一台 Windows 完成 Beta 差分准备、健康检查与三轮 Host。Only 五种拒绝场景、原版来源前后保护、每份安装的 47,937 个程序文件、源码绑定以及本地受控更新事务均已有范围明确的证据。不同环境的三轮不能合并成同一场景九轮。

兼容性报告的 840 条记录包含组件包和配置实例，不能理解为 840 个故障或 840 个用户插件。关键检查和定向测试不等于所有插件功能已经逐项验证。所有私人插件、外部 MCP、在线付费模型、任意多模态材料、多日高负载和任意官方桌面安装布局均没有获得全面保证。

原生 GUI 与在线资产回验以随发行的补充验证说明为准。安装包里的历史记录保留原日期和字节，不以新结论改写旧实验。

## 原生桌面补验

三轮正常启停、首次后台提示、同一宿主恢复已验证；手动拖动与首轮托盘由用户协助确认。实际更新审阅的取消和接受分别取得匹配签名回执；这些仅是隔离回执，不授权私人日常切换。早期自动输入失败、用户选择与预期不符、15 分钟超时及后续清理均保留，详见 NATIVE-GUI-VERIFICATION.md。GitHub 草稿资产在发布前进行完整下载流 SHA-256 比对。
