# Beta.3 技术与范围摘要

SEP 使用 Cordis 插件组合与固定宿主适配，分层记忆、预算、受管任务与平台保护分别接入。桌面安装包的分发版本是 0.2.1-beta.3；各平台沿用已验证的派生构建，子包版本并不统一。根组合包的待准入入口不是任意官方 DSH 的通用自动安装承诺。

## 记忆与 BM25

L1 是模型上下文；L2 保存项目资料与临时事项；L3 保存习惯、重要事实与项目目标；L4 保存按需访问的历史与归档。L2/L3 的持久记录、RAG 文档分块和辅助 SQLite 数据不是同一种对象。

本地 RAG 对获准来源核验身份、解析分块并保存来源哈希，查询时对获准候选做 BM25 词项排名。基础参数 `k1=1.2`、`b=0.75`；中文结合汉字/相邻双字与分词，英文使用规范化词项。它不需要远端 embedding，也没有以此训练模型权重；语义改写和跨语言查询可能漏检。作用域、状态、有效性和输出上限先于或独立于排名，不能把 BM25 描述成全部记忆决策。

Mem0 相关适配选择同项目、同会话的直接用户消息；可选模型提炼可能消耗 token，默认捕获关闭。历史展开按需授权，不将归档自动重新激活。注入模型上下文的检索片段仍会计入模型请求。

## 预算、执行与保护

共享累计、单会话和单轮限额分别计账；修改设置不清零消费或未知预留。默认单会话 100 元、单轮 5 元是本地估算护栏，不是服务商充值余额。

最多两个只读子任务、两次返工及相关统一取消记录仅适用于经 `suite_delegate` 创建的任务，不覆盖任意原生子代理和外部 Shell。外部请求超时不等于操作没有执行。

Windows 使用受管入口与生命周期保护，普通 Shell 不因此成为操作系统沙箱。Linux 使用命名空间与受控工作副本，提交需受信任控制方批准。Mac 采用限定系统版本的原生沙箱兼容与事务适配，仍有明确关闭的用户流程。三者不是同等隔离或全部功能认证。

根 `bundle/` 是已审查的组合基线；`tools/alpha2-windows/`、`tools/alpha2-portable/` 与 `tools/alpha2-macos/` 记录平台派生，Mac 的捕获副本与转换清单另外绑定。旧 `docs/TECHNICAL_OVERVIEW.md` 保留为其当时 Windows 版本的详细说明，涉及容量和服务接线时应同时核对本版平台说明，不能直接外推到全部平台。
