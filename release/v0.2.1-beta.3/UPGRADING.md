# 从旧版本迁移到 Beta.3

本次是三个平台的独立首次安装分发，主机均基于 DSH 0.2.1-alpha.2；没有发布可自动应用于任意旧库的升级候选。请选择新目录，先保留旧实例及其数据，按平台说明安装。

不要把 Full／Only／Linux／Mac 安装包交给旧版差分更新器，不要解压覆盖旧程序或私人库。旧 Beta.2 的离线桥只适用它原来列明的旧版本，不能据此升级到 Beta.3。程序运行时也不要直接移动目录。

本次提供 `RELEASE-MANIFEST.json` 作为分发与校验清单；它不是自动安装授权。没有伪造 `dsh-sep-update.json` 指向全新安装 ZIP：旧协议要求可安装的受控更新候选，不能将不同平台的首次安装包伪装成该候选。旧检查器可能仍显示“元数据不完整／需要适配”，这不代表上述 GitHub 手动下载不存在。

完整公网下载→原生确认→自动安装的同次正例仍待验证。发布文件可以下载，不等于更新链已经认证；后续版本迁移仍须核对原版本、插件、数据及具体计划。

本次没有切换维护者的 Windows 日常实例，没有重置消费账本，也不调整用户的更新过滤设置。
