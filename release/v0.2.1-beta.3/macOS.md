# macOS ARM64 · DSH SEP 0.2.1-beta.3 隔离预览

[下载 macOS 安装器](https://github.com/Lance-QwQ/DSH-SEP/releases/download/v0.2.1-beta.3/DSH-SEP-0.2.1-beta.3-macOS-arm64.zip)。统一分发版本为 **0.2.1-beta.3**；资产保留 r83 原生复验代次的新安装器原始字节，内含 DSH `0.2.1-alpha.2` 和 SEP Mac 派生运行时。它与 Windows／Linux 的内部派生版本不作相同版本号承诺。

实际验证环境为 **macOS 15.7.9 ARM64／APFS 的 GitHub hosted runner**。完整 macOS 公开认证仍为 **blocked**；Intel、其他 macOS 版本和所有 Mac 的通用可用性没有获得认证。

## 安装和退出

1. 下载 ZIP，核对以下 SHA-256 并完整解压。
2. 打开外层 **`DSH SEP Installer.app`**，审阅安装目标和具体计划后确认。安装完成后打开已安装应用是独立动作。
3. 固定安装目标是当前账户的 `~/Applications/DSH SEP.app`；独立数据目录是 `~/Library/Application Support/DSH SEP/alpha2-mac-finder-preview`。已有目标或未知事务会被拒绝，不提供强制覆盖、原位升级或自动卸载。不要将其解压覆盖现有应用或私人数据。
4. 模型凭据由使用者自行配置；本轮没有调用付费模型，也没有挂载用户私人库。
5. 关闭窗口可能保留后台，应使用应用的正常退出操作。不要删锁、修改账本或按进程名批量结束资源。

**签名为 ad-hoc，尚无 Developer ID 签名及公证。** Gatekeeper 和组织安全策略可能阻止运行；本发布不提供 Gatekeeper／TCC 绕过步骤。完整公共安装体验不因此标记通过。

## 当前功能范围

仅固定受控项目可用，工作副本／提交事务与原始来源隔离，普通文件编辑页面只读。任意 Shell、任务子进程、任意 MCP／Computer Use、Mac 自动更新安装，均未作为已认证用户流程开放。完整原生项目批准、全部受保护功能在同一桌面实例中联合运行、私人环境接续和付费模型仍未认证。

## 新原生验证证据

本轮经过三段独立绑定：新应用构建、固定新应用的安装器构建、固定安装器的真实安装与已安装产品启闭。135 个核心定义和 41 个业务定义具有重叠；业务组在构建前后执行仍是 41 个定义，不能累加成 82 个独立功能。

程序包中的 84 个运行时文件与当前源码逐项相同。业务测试使用真实宿主／Loader及原生依赖，但测试文件从当前源码加载，**不声称这些测试在 AppKit／Electron 内部执行**。模型适配器为合成，部分 parser 契约采用测试替代。

安装验证包括原字节安装器正常启动／退出、独立测试入口的真实 Cocoa 控件及 6 项安装断言、已安装应用两轮 LaunchServices 启动、同 Profile 保留和正常退出。测试副本替换 main，生产模块保持原字节；这不是原 main 的物理按钮输入或 Finder／Dock 物理点击认证。

本轮接受的安装／已安装产品样本没有强制测试清理。原安装器只观测正常退出与精确进程消失，其内部控制器 drain 未从外部观测；测试入口另有控制器 EOF／closed／exit 回执；产品有同代次正常关闭回执。未执行全局进程／句柄清点，`blocked` 不代表资源已经释放。

限定隐私扫描覆盖 16 个安装器运行时文本及字节相同的 84 个 payload 运行时文本；二进制、依赖、ASAR、AppleDouble 不在该扫描范围，不是全面隐私证明。
